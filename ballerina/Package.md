## Overview

[Microsoft OneNote](https://www.microsoft.com/en-us/microsoft-365/onenote/digital-note-taking-app) is a digital note-taking application that provides a single place for keeping all of your notes, research, plans, and information — everything you need to remember and manage in your life at home, at work, or at school.

The Microsoft OneNote connector offers APIs to connect and interact with the OneNote REST API, providing the capability to access a user's OneNote notebooks, sections, and pages in a personal account.

### Key Features

- Access and manage OneNote notebooks, sections, and pages
- Support for Microsoft Graph API v1.0
- Programmatic interaction with digital note-taking content
- Secure integration with Microsoft 365 personal accounts
